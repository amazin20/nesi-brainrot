# Техническое задание — «Неси Брейнрот: Небесный забег»

## 1. Цель вертикального среза

Создать законченную браузерную 3D-демку, которую можно открыть по ссылке GitHub Pages без установки. Игрок должен сразу понимать цель, пройти короткий уровень за 2–4 минуты и захотеть улучшить время.

## 2. Игровая идея

Игрок управляет персонажем-моделью №1. В начале трассы он подбирает брейнрота-модель №2 и должен донести его до финиша. Модели №3–10 формируют полосу препятствий. Падение или удар возвращают игрока на последний активированный чекпоинт, но не обнуляют весь забег.

## 3. Игровой цикл

1. Запуск и загрузка ассетов.
2. Короткий экран с целью и управлением.
3. Автоматический подбор груза на стартовой площадке.
4. Прохождение пяти секций трассы.
5. Активация двух чекпоинтов.
6. Финиш с грузом, фиксация результата и лучшего времени.
7. Повторный забег одной кнопкой.

## 4. Роли GLB-моделей

| № | Роль в демке |
|---:|---|
| 1 | Игровой персонаж |
| 2 | Переносимый брейнрот-груз |
| 3 | Большой качающийся молот |
| 4 | Пружинящая/движущаяся платформа |
| 5 | Арка чекпоинта |
| 6 | Финишный флаг |
| 7 | Вращающийся ударный молот |
| 8 | Вращающийся ролик |
| 9 | Секция барьеров |
| 10 | Небесные платформы |

## 5. Секции уровня

- Стартовая площадка и автоматический подбор груза.
- «Маятники»: три качающихся препятствия с телеграфируемым движением.
- «Батуты»: движущиеся блоки, ускоряющие прыжок.
- «Роллер»: вращающееся препятствие с боковым отталкиванием.
- «Барьеры»: серия прыжков с безопасными зонами.
- «Небесные острова»: финальная цепочка платформ и флаг.

## 6. Управление

- ПК: `WASD`/стрелки — движение, `Space` — прыжок, `R` — рестарт, `Esc` — пауза.
- Телефон/планшет: экранный джойстик и отдельная кнопка прыжка.
- Камера: плавное автоматическое следование с обзором трассы.

## 7. Физика и правила

- Персонаж использует устойчивый кинематический контроллер.
- Есть гравитация, прыжок, ускорение, торможение, ограничение скорости и проверка пола.
- Препятствия наносят импульс, но не вызывают мгновенный проигрыш.
- Падение ниже уровня возвращает на последний чекпоинт.
- Победа засчитывается только при достижении финиша с грузом.

## 8. Интерфейс

- Прогресс загрузки моделей.
- Цель, таймер, прогресс трассы, статус груза и номер чекпоинта.
- Подсказки управления, пауза, сообщения о чекпоинте/падении.
- Экран победы с текущим и лучшим временем из `localStorage`.

## 9. Визуальный стиль

- Яркий «небесный фестиваль»: глубокий градиентный фон, туман, цветные платформы, световые кольца и частицы.
- Все интерактивные элементы читаются по цвету и движению.
- Модели используются в исходных материалах; окружение дополняется процедурной геометрией Three.js.

## 10. Техническая архитектура

- Vite + Three.js.
- GLTFLoader + DRACOLoader для оптимизированных GLB.
- Никаких серверных зависимостей: статическая сборка для GitHub Pages.
- Ограниченный pixel ratio, адаптивные тени и корректный resize.
- Ассеты расположены в `public/models`, Draco-декодер — в `public/draco`.
- GitHub Actions собирает `dist` и публикует его в GitHub Pages.

## 11. Критерии готовности

- `npm run check` завершается без ошибок.
- Все 10 GLB входят в production-сборку и доступны по относительным URL.
- Игровой цикл старт → груз → препятствия → чекпоинты → финиш → рестарт работает.
- Управление доступно на клавиатуре и сенсорном экране.
- Прямое обновление страницы GitHub Pages не ломает загрузку ассетов.
- README содержит актуальную игровую ссылку и локальные команды запуска.

## 12. Следующий этап после демки

- Риг и анимации персонажа.
- Система падения/возврата груза и несколько видов брейнротов.
- Противники или гонка с призраком лучшего результата.
- Звуки, музыка, настройки качества и локализация.
- Подготовка SDK и рекламы для публикации в Яндекс Играх.
