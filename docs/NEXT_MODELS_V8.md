# Next models, with purpose — not additional clutter for levels 1–5

The first five courses use existing models. No new character is required. All originals, including retired props, stay in the repository; only twelve useful dependencies ship in the five-course package, six load initially.

| New ID | Model | Actual future purpose | First planned introduction |
|---|---|---|---|
| 31 | Inertial sphere | Rolls down a ramp, preserves angular and linear momentum through a portal, activates an impact receiver by kinetic energy rather than sitting on a switch. | 6–7 |
| 32 | Spring impact receiver | Separate cup, piston and stationary housing. A weak hit visibly compresses the spring but does not latch; a sufficient momentum pulse powers a circuit. | 7–8 |
| 33 | Counterbalanced seesaw | Separate lever, fulcrum and two trays. Visible torque and load positions affect the angle; a portal-transferred object can tip it from a distance. | 9–10 |

Style: pale mint ceramic, graphite ribbed metal and restrained bronze fasteners. One isolated 3/4 product render per model; no collage, text or extra scenery. These renders are MODEL CONCEPTS, never game screenshots. Future import needs a GLB, Y-up metre scale, sane pivots, separate moving parts, one 1024 texture set and approximately 3–8k triangles; detailed source may be optimized separately. No requirement to regenerate the existing player.

## Direction for 100 courses (planned, NOT implemented)
1–5: orientation, linked space, height-to-speed, lift, real load and exit direction.
6–15: rolling, impacts, angular momentum, load position and levers.
16–30: coupled portal circuits, movable surfaces and transporting separate objects.
31–50: timing with predictable mechanical cycles and alternate routes, not reflex-only failure gates.
51–75: combining known rules with multiple independent physical bodies.
76–100: multi-stage chambers where a solution changes the space itself. New mechanics require one safe teaching room before combinations. No hint-only solutions, random unwinnable seeds or decorative fake machines.
