# Следующие основные модели

Рабочий маршрут использует существующие стены, двери, панели, нажимные площадки, терминалы и подъёмник. Следующий набор заменит простые геометрические части уровня на согласованные художественные модели.

| Приоритет | Модель | Требования и назначение |
| --- | --- | --- |
| 1 | Секция подвижного моста | Одна ровная секция, отдельный корпус и настил. Повторяется над разрывами; физический путь для брейнрота. |
| 2 | Лестница или пологий пандус | Широкий чистый проход, ровные ступени без мелких выступов. Выход из нижних площадок и переходы высоты. |
| 3 | Модуль перил | Прямая повторяемая секция и простой угол. Читаемые границы мостов и верхних площадок. |
| 4 | Настенный/потолочный светильник | Один простой вытянутый корпус с крупной светящейся вставкой. Повторяется по всему уровню. |

Каждый объект — отдельный GLB. Палитра: тёплый белый, тёмный серо-синий, небольшие бирюзовые и коралловые вставки. У подвижного объекта детали должны быть отдельными mesh-узлами. Для текущего маршрута геометрические версии этих объектов уже создаются кодом.

Следующий тип головоломки: лазерная цепь. Для неё нужны излучатель, приёмник и отражатель, который можно закрепить на существующем спутнике. Сам луч и его связи с механизмами выполняются кодом. Позже можно добавить генератор светового моста и транспортирующего луча. Эти дополнительные системы пока не входят в текущий уровень.
