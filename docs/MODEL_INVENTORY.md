# Model inventory

The active laboratory uses 14 assets: the original player (01), brainrot cargo (02), portal gun (11), and eleven new environment models (12–22). Old environment assets 03–10 were removed from the active project and remain recoverable in Git history.

See [MODEL_MANIFEST.md](MODEL_MANIFEST.md) for the current filenames, original uploads, roles, triangle counts, optimization notes, and source/runtime checksums. The runtime mapping is maintained in [`src/game/labAssets.js`](../src/game/labAssets.js).

Individual rendered screenshots are available in [`public/gallery.html`](../public/gallery.html).
