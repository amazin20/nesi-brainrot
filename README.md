# Неси Брейнрот: Небесный забег

Играбельная браузерная 3D-демка: подбери брейнрота и донеси его через полосу препятствий до финиша.

## Играть

После первого успешного деплоя игра будет доступна здесь:

**https://amazin20.github.io/nesi-brainrot/**

## Управление

- `WASD` или стрелки — движение
- `Space` — прыжок
- `R` — начать забег заново
- `Esc` — пауза
- На телефоне отображаются джойстик и кнопка прыжка

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run check
npm run preview
```

Полное игровое и техническое ТЗ находится в [GAME_DESIGN.md](GAME_DESIGN.md).
