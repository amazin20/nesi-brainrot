# NESI / Transfer Lab

Браузерная 3D-головоломка от третьего лица. Три связанные лабораторные комнаты и один постоянный спутник. Через порталы можно проходить с брейнротом в руках; мосты, подъёмник и пандусы дают дополнительные пути. Без таймера и гонки; планировка собственная.

**[Играть на GitHub Pages](https://amazin20.github.io/nesi-brainrot/)** · **[Все модели](https://amazin20.github.io/nesi-brainrot/gallery.html)** · **[Новые объекты](https://amazin20.github.io/nesi-brainrot/concepts.html)**

Демка собирается и публикуется из `main` через GitHub Actions. Перед публикацией выполняются тесты, сборка и полное прохождение на геометрии исходных GLB. `build-info.json` на странице демки содержит точный опубликованный commit.

## Управление

- WASD / стрелки — движение, Shift — бег, Space — прыжок.
- Мышь — камера. ЛКМ / ПКМ — голубой / оранжевый портал на белой панели.
- F — удерживать прицел: персонаж смотрит по камере, доступны боковые шаги и движение спиной.
- E — взять / отпустить брейнрота или включить терминал рядом. Нажимные площадки связаны с замками.
- Пушка закреплена в правой кисти; при переносе брейнрота обеими руками она убирается на крепление.
- X — сбросить пару порталов. Один портал можно оставить под брейнротом, второй открыть после перехода двери.
- V — радостно помахать свободной рукой.
- R — начать заново, Esc — пауза.

Исходные GLB игрока, Brainrot и пушки сохранены без изменений. Персонаж получает скелет на 14 костей во время загрузки. Стопы фиксируют опору в фазе шага; таз и плечи следуют за переносом веса, прыжок начинается с короткого приседания. Исходная слитая геометрия ограничивает большие сгибы одежды. Брейнрот получает отдельный скелет на 7 костей: голова, хвост, плавники и ноги.

Физика работает на 120 Гц, а анимация и интерполяция обновляются каждый кадр игры. Порталы рисуются каждый кадр с HDR и сглаживанием при поддержке GPU. Брейнрот имеет массу, вращение, контактное трение и коллизии даже при переноске. После падения он физически встаёт и понемногу гуляет рядом; на нажимной плите остаётся ждать. Бег, прыжки, батут и порталы работают при переноске. Стрелять с занятыми руками нельзя.

На стол и кресло в первой комнате можно запрыгнуть. Пять новых модулей 23–27 используются для пола, белых портальных стен, пандусов и перил. Их игровые копии содержат на 96% меньше треугольников; оригиналы сохранены для галереи. Старые модели 03–10 удалены из актуальной версии. Состав и происхождение: [MODEL_MANIFEST.md](docs/MODEL_MANIFEST.md).

Обычный выстрел не меняет камеру. Кисти следуют за фактическими точками хвата брейнрота через IK; шаг и прыжок имеют плавные переходы. Створки дверей расходятся в стороны при неподвижной раме; энергетическое поле затухает между неподвижными опорами. Двери и поле открыты, пока на связанной плите лежит брейнрот, и закрываются после снятия веса. Датчик прохода даёт закончить пересечение. Белый вкладыш плиты принимает портал: спутника можно забрать с другой стороны.

## Разработка

```bash
npm ci
npm run dev
npm run check
```

Текущий проход: [CHARACTER_FEEL_V5.md](docs/CHARACTER_FEEL_V5.md). `node scripts/lab-journey.mjs` загружает геометрию всех 19 GLB и проверяет полный маршрут с настоящими коллизиями и камерой. Отчёт: [continuous-journey.json](qa/continuous-journey.json). В GitHub Actions также предусмотрены проверки в Chromium и запись WebGL; их наличие не означает, что визуальный прогон выполнен локально. `?debug=1` включает диагностический объект; `?smoke=1` запускает игру для автоматизированной проверки. `?evidence=1` открывает отдельную панель проверки поз, прохождения и записи; в обычной игре этой панели нет.

Три отдельных концепта будущих объектов: [галерея](public/concepts.html). Иллюстрации не выданы за готовые 3D-модели.
