# Неси Брейнрот: Небесный забег

Играбельная браузерная 3D-демка: подбери брейнрота и донеси его через полосу препятствий до финиша.

## Играть

После первого успешного деплоя игра будет доступна здесь:

**https://amazin20.github.io/nesi-brainrot/**

Новый режим **Rift Lab** от третьего лица:

**https://amazin20.github.io/nesi-brainrot/?mode=rift**

Это не копия механики Portal. В Rift Lab используется один переставляемый
разлом-маяк: игрок строит к нему видимую фазовую траекторию, проходит сквозь
отмеченную стену и получает импульс из накопленной скорости. Brainrot-куб можно
переносить по тому же маршруту.

## Управление

- `WASD` или стрелки — движение
- `Space` — прыжок
- `ЛКМ` — поставить разлом-маяк на фазовой стене
- `ПКМ` или `Q` — запустить фазовый маршрут
- `E` — взять или бросить Brainrot-куб
- `R` — начать забег заново
- `Esc` — пауза
- На телефоне отображаются джойстик и кнопка прыжка

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run check
npm run preview
```
