# NESI / Transfer Lab

Браузерная 3D-головоломка от третьего лица. Три связанные лабораторные комнаты и один постоянный спутник. Через порталы можно проходить с брейнротом в руках; мосты, подъёмник и пандусы дают дополнительные пути. Без таймера и гонки; планировка собственная.

**[Играть](https://amazin20.github.io/nesi-brainrot/)** · **[Все модели](https://amazin20.github.io/nesi-brainrot/gallery.html)**

## Управление

- WASD / стрелки — движение, Shift — бег, Space — прыжок.
- Мышь — камера. ЛКМ / ПКМ — голубой / оранжевый портал на белой панели.
- F — удерживать прицел: персонаж смотрит по камере, доступны боковые шаги и движение спиной.
- E — взять / отпустить брейнрота или включить терминал рядом. Нажимные площадки связаны с замками.
- Пушка закреплена в правой кисти; при переносе куба обеими руками она убирается на крепление.
- V — радостно помахать свободной рукой.
- R — начать заново, Esc — пауза.

Исходные GLB игрока, Brainrot и пушки сохранены без изменений. Персонаж получает скелет на 14 костей во время загрузки. У модели есть слитые участки рукавов и куртки, поэтому анимация использует ограниченные углы и консервативные веса.

Физика работает на 120 Гц, а анимация и интерполяция обновляются каждый кадр игры. Порталы рисуются каждый кадр с HDR и сглаживанием при поддержке GPU. Брейнрот имеет массу, вращение, контактное трение и коллизии даже при переноске.

На стол и кресло в первой комнате можно запрыгнуть. Пять новых модулей 23–27 используются для пола, белых портальных стен, пандусов и перил. Их игровые копии содержат на 96% меньше треугольников; оригиналы сохранены для галереи. Старые модели 03–10 удалены из актуальной версии. Состав и происхождение: [MODEL_MANIFEST.md](docs/MODEL_MANIFEST.md).

Обычный выстрел не меняет камеру. Кисти следуют за фактическими точками хвата брейнрота через IK; шаг и прыжок имеют плавные переходы. Створки дверей расходятся в стороны при неподвижной раме; энергетическое поле затухает между неподвижными опорами.

## Разработка

```bash
npm ci
npm run dev
npm run check
```

ТЗ текущего прохода: [CHARACTER_FEEL_V4.md](docs/CHARACTER_FEEL_V4.md). GitHub Actions проверяет физику и прохождение всех трёх камер в Chromium, снимает настоящий WebGL-кадр и ролик анимации. `?debug=1` включает диагностический объект; `?smoke=1` запускает игру для автоматизированной проверки. `?evidence=1` открывает отдельную панель проверки поз, прохождения и записи; в обычной игре этой панели нет.
