# NESI / Transfer Lab

Браузерная 3D-головоломка от третьего лица. Три связанные лабораторные комнаты и один постоянный спутник. Порталы перемещают игрока, а брейнрот путешествует физически: по мостам, на подъёмнике и в руках. Без таймера и гонки; планировка собственная.

**[Играть](https://amazin20.github.io/nesi-brainrot/)** · **[Все модели](https://amazin20.github.io/nesi-brainrot/gallery.html)**

## Управление

- WASD / стрелки — движение, Shift — бег, Space — прыжок.
- Мышь — камера. ЛКМ / ПКМ — голубой / оранжевый портал на белой панели.
- F — удерживать прицел: персонаж смотрит по камере, доступны боковые шаги и движение спиной.
- E — взять / отпустить брейнрота или включить терминал рядом. Нажимные площадки связаны с замками.
- Пушка закреплена в правой кисти; при переносе куба обеими руками она убирается на крепление.
- V — радостно помахать свободной рукой.
- R — начать заново, Esc — пауза.

Исходные GLB игрока, Brainrot и пушки сохранены без изменений. Персонаж получает скелет на 14 костей во время загрузки. У модели есть слитые участки рукавов и куртки, поэтому анимация использует ограниченные углы и консервативные веса.

Физика работает на 120 Гц, а анимация и интерполяция обновляются каждый кадр игры. Порталы рисуются каждый кадр с HDR и сглаживанием при поддержке GPU. Брейнрот имеет массу, вращение, контактное трение и коллизии даже при переноске.

Мебель 12–15 сохранена в галерее; все модели на маршруте выполняют игровые функции. Старые модели 03–10 удалены из актуальной версии. Добавлены 11 новых моделей окружения, суммарно 5,21 MiB. Состав и происхождение: [MODEL_MANIFEST.md](docs/MODEL_MANIFEST.md).

## Разработка

```bash
npm ci
npm run dev
npm run check
```

ТЗ: [LAB_DESIGN.md](LAB_DESIGN.md). GitHub Actions проверяет физику и прохождение всех трёх камер в Chromium, снимает настоящий WebGL-кадр и ролик анимации. `?debug=1` включает диагностический объект; `?smoke=1` запускает игру для автоматизированной проверки.
